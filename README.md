# Order Management Dashboard

A responsive Order Management Dashboard built using React and Vite.

This project is based on the provided OMS (Order Management System) reference screen and focuses on reusable components, responsive UI, and clean folder structure.

---

# Features

- Responsive Dashboard Layout
- Sidebar Navigation
- Order Summary Section
- Order Details Section
- Order Breakdown Table
- Customer Details Section
- Activity Timeline Panel
- Reusable Components
- Dynamic Data Rendering using Mock Data
- Mobile Responsive Design

---

# Tech Stack

- React
- JavaScript
- CSS3
- Vite
- Remix Icons
